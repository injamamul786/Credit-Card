# 💳 Credit Card Spending Dashboard - Power BI Project

This is a **Power BI end-to-end data analysis project** inspired by a practical YouTube tutorial. The project demonstrates how to import, clean, analyze, and visualize credit card spending data using Power BI. It’s designed to provide clear insights into customer behavior and transaction trends.

## 📊 Dashboard Highlights

- Total and Weekly Credit Card Spend
- Transaction Trends by Week
- Top Performing Categories & Merchants
- Customer Demographics & Segmentation
- Interactive Filters for City, Category, and Time Period

## 🛠️ Tools & Technologies

- **Power BI Desktop**
- **Excel/CSV Dataset**
- **DAX (Data Analysis Expressions)**
- **Power Query (ETL)**
